# Escape the Backrooms

Ein Horror-Spiel in der Ich-Perspektive, das komplett im Browser läuft – ohne Installation, ohne Bilder- oder Sounddateien. Alles (Grafik, Monster, Geräusche) wird direkt im Code erzeugt.

## Level

| Level | Ort | Monster | Ziel |
|---|---|---|---|
| 1 | **Die Backrooms** – gelbe Räume, Neonlicht | Der große graue Mann ohne Gesicht mit dem breiten Lächeln | Schraubenzieher in den Schubladen finden, Gullideckel öffnen |
| 2 | **Die Poolrooms** – gekachelte Becken, dunkelgrünes Wasser | Der Kappa – blind, hört dich aber im Wasser | Über Plattformen springen, 3 rote Schalter aktivieren |
| 3 | **Die Stromzentrale** – dunkle Betontunnel, rote Notlampen | Die Porzellan-Spinne – erstarrt im Licht der Taschenlampe | 3 Sicherungen finden und den Strom zurückbringen |

Jedes Level endet mit einer eigenen Zwischensequenz.

## Steuerung

| Taste | Aktion |
|---|---|
| W A S D | Laufen |
| Maus / ← → | Umsehen (ins Bild klicken für Maussteuerung) |
| Shift | Rennen |
| E | Benutzen (Gully, Schalter, Sicherungskasten) |
| 1 / 2 / 3 | Schublade öffnen (Level 1) |
| F | Bärenfalle legen (Level 1) · Taschenlampe (Level 3) |
| Q | Energy-Drink trinken (Level 1) |
| Leertaste | Springen (Level 2) |
| M | Große Karte (Level 1) |
| Esc | Pause |

Kopfhörer empfohlen.

## Spielen

- **Lokal:** `index.html` doppelklicken – das Spiel öffnet sich im Browser.
- **Online mit GitHub Pages:** Repository → *Settings* → *Pages* → bei *Source* „Deploy from a branch“ wählen, Branch `main` und Ordner `/ (root)` → *Save*. Nach ca. einer Minute läuft das Spiel unter `https://<dein-name>.github.io/<repo-name>/`.
